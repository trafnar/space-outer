# Space Outer

Space Outer is a Next.js app for reviewing test scores and generating printable worksheets.

## Development

This project uses pnpm. The `preinstall` script runs `only-allow` so installs with npm or Yarn fail fast.

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 after the dev server starts.

## Scripts

```bash
pnpm dev
pnpm build
pnpm start
pnpm lint
```
